# Changelog

## Initial Bug Fixes
- **File:** `initialisation.go`
  - **What:** Removed the hardcoded dummy ant instantiation and `IsOccupied` check during parsing. Defaulted `chamber.occupied` to `false`.
  - **Why:** The parser was creating a fake ant at `[23, 3]` and checking `IsOccupied` for every chamber during parsing. This incorrectly set the `occupied` state based on a non-existent ant rather than actual simulation state. All rooms should start unoccupied.
  - **What:** Updated tunnel detection from `strings.Contains(trimmedLine, "-")` to also require `len(strings.Fields(trimmedLine)) == 1`.
  - **Why:** Room definitions with negative coordinates (e.g., `room1 5 -10`) contain a `-` and were being misidentified as tunnels. Adding the single-field check ensures only actual tunnel lines like `1-3` are matched.

- **File:** `algo.go`
  - **What:** Fixed `Canmove` — removed `room.tunnels = nil` and changed to return `false` when occupied.
  - **Why:** The original code set `room.tunnels = nil` when a room was unoccupied, which permanently destroyed the graph connections. It also always returned `true` regardless of occupancy, making the function useless.

- **File:** `main.go`
  - **What:** Added `if len(ants) > 0` guard before accessing `ants[0].coordination`.
  - **Why:** If the input specifies `0` ants, accessing `ants[0]` causes a runtime panic (index out of bounds).

## Heap / Priority Queue Addition
- **File:** `algo.go`
  - **What:** Added `Item` struct and `PriorityQueue` type implementing `container/heap` interface with methods `Len`, `Less`, `Swap`, `Push`, `Pop`.
  - **Why:** Required for priority-based graph traversal (Dijkstra-style) to find paths through the colony efficiently. Uses the standard Go `container/heap` package.

## FindFastestPath Implementation
- **File:** `algo.go`
  - **What:** Added `FindFastestPath(start, end *chamber) []*chamber` function using the `PriorityQueue`.
  - **Why:** Core pathfinding function. Uses Dijkstra's algorithm with the heap to find a path from `##start` to `##end`. Skips rooms marked `occupied` (except start/end) to enable finding multiple vertex-disjoint paths when called repeatedly.
